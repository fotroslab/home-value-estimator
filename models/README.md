# Models

Artifacts generated by `train.py` from `data/sample_properties.csv` (Allegheny County snapshot 2026-10-30):

- `xgb_model.joblib` — primary model (XGBoost 400 trees, depth 6)
- `ridge_model.joblib` — transparent fallback (Ridge α=10)
- `preprocessor.joblib` — fitted ColumnTransformer (impute + one-hot + scaler)
- `metrics.json` — real holdout metrics (RMSE/MAE/R² + interval)
- `band_metrics.csv` — error by price band
- `shap_bar.png` — global mean |SHAP|
- `residual_plot.png` — residuals vs predicted + histogram
- `shap_importance.csv` — top features by mean |SHAP|
- `sample_input.json` — example valid input for testing

All metrics are from the current execution — no copied numbers. To regenerate:

```bash
python train.py
```

To reproduce from the full CC0 source, download per `data/README.md` and re-run the notebook.
